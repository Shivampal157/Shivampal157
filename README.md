## 🚀 Key Projects (From Resume)

### ⚡ [CodeSentinel AI](https://github.com/Shivampal157/CodeSentinel-AI) — *Distributed RAG Code Intelligence Platform*
- **Architecture:** Asynchronous worker pipeline using **BullMQ** & **Redis**, decoupling AST parsing from API threads to sustain **sub-100ms latency** and **99.8% job reliability**.
- **Vector Search:** Integrated **Qdrant Vector DB** (1536-d HNSW indexing) with payload filtering and **diffHash Redis caching**, cutting LLM costs by **75%** with `<120ms` retrieval.
- **Tech Stack:** `TypeScript` · `React 18` · `Express.js` · `MongoDB Atlas` · `Redis` · `BullMQ` · `Qdrant` · `Docker` · `Socket.io`

<br/>

### 🏥 [MediCare](https://medi-care-two-blush.vercel.app) — *Scalable Enterprise Healthcare Platform*
- **Scalability:** Enterprise platform serving **3 distinct user roles** with Google OAuth 2.0, 30+ modular REST APIs, and MongoDB indexing on `sessionId` accelerating queries by **40%**.
- **Payments & Deployment:** Automated payment workflows via **Stripe API** and webhooks, deployed across **Vercel** and **Render** maintaining **99.9% uptime**.
- **Tech Stack:** `MongoDB Atlas` · `Express.js` · `React.js` · `Node.js` · `JWT` · `Google OAuth 2.0` · `Stripe API` · `Tailwind CSS`

<br/>

### 📡 [AlgoRadar](https://algoradar-cp.streamlit.app) — *Concurrent Analytics & Data Ingestion Engine*
- **Concurrent Ingestion:** Multi-threaded client pool querying external services concurrently, fetching **2,500+ live records** in under **1.5 seconds**.
- **Caching:** Multi-tier disk caching with automated TTL eviction (6h/24h/7d) across 1,200+ records, reducing redundant network calls by **80%**.
- **Tech Stack:** `Python` · `Streamlit` · `pandas` · `NumPy` · `RESTful APIs` · `GraphQL` · `scikit-learn` · `pytest`
